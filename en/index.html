01 — The customer explains

Understands the project — not just the words.

Atlas works out what needs doing, where, and which products belong to the job — including the easily forgotten ones, such as primer. If something is unclear, Atlas asks rather than guesses.

02 — Atlas finds the product

An exact code gives the exact product.

The catalogue is based on NOBB, the Norwegian building industry’s product database. Search by name when the customer describes the product — or use the code when you have it in front of you. If a code finds nothing, Atlas says so and never suggests a “nearest” product.

05 — Honesty

Atlas tells you when it does not know.

An in-store assistant has to be trustworthy. That is why Atlas shows what is documented, what is approximate and what is only an illustration.

  • Approximate

    Colours from a documented code

    A colour is only shown when the product itself states a colour code such as NCS or RAL, or the customer gives their own. It is always marked as approximate: a screen is not a colour sample.

  • Illustration

    Illustrations are labelled

    When there is no faithful rendering of a product, Studio shows a neutral surface labelled “Illustration” — never an image pretending to be the product.

  • Unresolved

    No orders on a guess

    A line without a chosen product stays “Unresolved”. Atlas never marks anything as ready to order on a guess.

  • Professional

    A tool, not the final word

    Load-bearing work, wet rooms, fire safety, electrics and other critical matters must always be confirmed by a qualified professional.
